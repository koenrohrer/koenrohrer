## Hey, I'm Koen

I build tools that help developers work with AI agents. Currently focused on developer tooling, agentic workflows, and making AI agent configurations less painful.

**What I'm working on:**

- **agentic-ide** -- VS Code extension for managing AI agent configurations across Claude, Codex, Ollama, and more
- **[parkinsons-voice-detector](https://github.com/koenrohrer/parkinsons-voice-detector)** -- Parkinson's disease detection using voice biomarkers
- **[nc-sc-county-map](https://github.com/koenrohrer/nc-sc-county-map)** -- Interactive county map for NC & SC
